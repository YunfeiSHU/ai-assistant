# 异步任务与重试

## 任务状态机

任务状态取值：PENDING、QUEUED、RUNNING、SUCCEEDED、FAILED、CANCELED。
状态迁移采用显式白名单：只有白名单内的迁移被允许，非法迁移直接报错而不是静默忽略。
SUCCEEDED 与 FAILED 都是终态，终态不可再迁移。

## 任务执行器

任务执行器有三种：none 表示只建任务不执行，inline 表示在 API 进程内同步执行，kafka 表示投递到消息队列由独立 Worker 消费。
生产环境使用 kafka，本地开发可使用 inline。

## 重试策略

失败任务最多重试 3 次（不含首次执行）。
退避间隔按指数增长：第 1 次重试等 1 秒，第 2 次等 4 秒，第 3 次等 16 秒。
退避队列使用有序集合存储，并通过 Lua 脚本原子认领，避免多个 Worker 抢到同一个任务。

## 补偿扫描

补偿扫描每 60 秒执行一次，负责找回「已到重试时间但没有被认领」的任务。
扫描是幂等的：同一个任务被扫描多次不会导致重复执行。

## 任务超时

单个任务的执行超时是 300 秒。超时后任务被标记为 FAILED，并记录超时原因。
