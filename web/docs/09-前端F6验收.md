## 2. 键盘与 a11y

- `Modal`：
  - `role=dialog` + `aria-modal` + `aria-labelledby`；
  - 打开时焦点进入对话框（优先第一个非关闭按钮控件）；
  - Tab / Shift+Tab 在可聚焦元素间循环；
  - Esc 关闭；关闭后恢复打开前的焦点；
  - 打开期间锁定 `body` 滚动，关闭恢复。
- 全局 `⌘K` / `Ctrl+K` 聚焦会话搜索。
- 发送框：Enter 发送、Shift+Enter 换行；生成中停止按钮可键盘触发。
- 删除/重新生成入口都有 `title` 与 `data-testid`，按钮可 Tab 到达。

## 3. 错误码动作表

实现：`web/src/shared/api/error-actions.ts`；流式错误卡展示“建议：…”。

| 错误码 | 建议动作 |
| --- | --- |
| `TOKEN_EXPIRED` / `UNAUTHENTICATED` / `INVALID_REFRESH_TOKEN` | 重新登录 |
| `INVALID_CREDENTIALS` | 检查邮箱/密码 |
| `USER_DISABLED` | 联系管理员（无自动动作） |
| `RATE_LIMITED` | 按倒计时等待 |
| `QUOTA_EXCEEDED` | 查看配额 |
| `CONVERSATION_ARCHIVED` | 取消归档 |
| `AI_UNAVAILABLE` / `AI_OVERLOADED` / `AI_TIMEOUT` / `DEPENDENCY_UNAVAILABLE` / `SERVICE_SHUTTING_DOWN` / `INTERNAL_ERROR` | 稍后重试 |
| `INVALID_ARGUMENT` | 检查输入 |
| `PAYLOAD_TOO_LARGE` | 缩小文件 |
| `UNSUPPORTED_MEDIA_TYPE` | 更换文件类型 |
| `EMAIL_ALREADY_EXISTS` | 换邮箱或登录 |
| `CONVERSATION_NOT_FOUND` / `MESSAGE_NOT_FOUND` / `RESOURCE_NOT_FOUND` | 返回列表/刷新 |
| `SUMMARY_UNAVAILABLE` | 可重建摘要（无自动动作） |
| 未知码 | 无自动动作 |

> 动作表只给出“下一步建议”，不自动重试：429/配额/鉴权自动重试会放大问题。

## 5. B-02 / B-03 / B-04 验收

### B-02 查看原文

- 真实存储：`GET /documents/{id}/download` → 302 预签名 URL；`/download-url` 返回 URL。
- 内存存储：`/download` 直接返回字节，`/download-url` 返回 `url=null`。
- 引用卡“查看原文”：有 URL 新窗口打开；无 URL 用 Bearer 拉字节后 `blob:` 打开。
- 实测（内存）：上传 `download.md` → `/download-url` 200 `url=null` → `/download` 200 `text/markdown` 977B。

### B-03 重新生成

- `POST /messages/{message_id}/regenerate`；复用上一条 user，只写新 assistant。
- 实测：消息保持 2 条（原 user + 新 assistant）；上下文 2 条；旧 assistant 被替换。
- 当前为**非流式**；流式重新生成留作后续增强。

### B-04 删除消息

- 删除前上下文 2 条；删除 assistant 后 1 条，摘要失效；会话 `message_count` 2 → 1。
- 前端二次确认，提示“长期记忆不会自动清除”。
- 上下文同步失败时台账保留，接口返回错误，避免“台账没了、模型还记得”。
