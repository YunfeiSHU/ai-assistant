## 实现

- 侧栏真实会话列表：每页 **20** 条、游标分页、搜索（280ms 防抖）、加载更多、错误重试。
- 新建对话：`POST /conversations` 后跳 `/chat/{id}`；空标题显示“未命名对话”。
- 会话页：`GET /conversations/{id}` + `GET .../messages?order=desc`（每页 30，翻成时间顺序）。
- 操作：改名（`PATCH title`）、置顶（`PATCH pinned`）、归档/取消归档、删除（二次确认）。
- 归档：横幅提示 + 输入框禁用；取消归档后恢复。
- 助手正文：`react-markdown + remark-gfm + rehype-sanitize`，模型输出按不可信内容处理。
- 查询失效：会话创建/改名/归档/删除后统一失效 `['conversations']`；删除时移除详情与消息缓存。

## 本轮发现并修复

1. **认证前挂查询**：`AppLayout` 在 `status=booting` 时就挂载了会话查询，导致无 token 的
   `401 UNAUTHENTICATED`，并与 refresh 竞态。修法：拆成“认证门 + 已认证壳”，查询只在 authed 后挂载。
2. **Markdown 原样显示**：助手正文里的 `**`、列表、代码块直接以纯文本出现。修法：引入
   `react-markdown` + sanitize，F3 直接复用。
3. **分页口径**：侧栏原为 30/页，55 条只有 2 页；改为 20/页后与计划的 3 页一致。

## 边界

- 流式对话尚未接入（F3）；输入框在 F2 是禁用的。
- 侧栏包含已归档会话（带“已归档”标记），保证归档后可回来取消；暂未做独立归档筛选页。
- 删除为软删，前端不做回收站。
- Markdown 只做 GFM + sanitize；引用角标、工具轨迹、KaTeX 在 F3 补。
- 首屏 JS 目前 **166.6 KB gzip**（Markdown 依赖进入主包），仍在 F6 的 180 KB 预算内；
  F6 会把会话页/Markdown 做路由级拆包。
