## F1 · 登录与启动恢复

### 自动化验收

```powershell
cd web
pnpm e2e
```

脚本 [`e2e/f1-smoke.mjs`](../e2e/f1-smoke.mjs) 用本机 Chrome（playwright-core，`channel: "chrome"`）跑：

1. `/login` → 切到「注册」→ 填昵称 / 邮箱 / 密码 → 提交；
2. 等待 `/chat`，断言侧栏昵称是刚注册的昵称；
3. **刷新页面**，断言仍在 `/chat`（说明 refresh 单飞恢复成功）；
4. 点退出，断言回到 `/login`，且 `ai_refresh` HttpOnly Cookie 已清、旧 `localStorage` key 为空；
5. 用错误密码再登录一次，断言错误区域展示 `INVALID_CREDENTIALS`；
6. 收集 `pageerror` 与控制台 error（网络 4xx 预期失败除外），有则失败。

结果：`PASS F1 注册 → 登录 → 刷新恢复 → 退出 → 失败态`。

截图：[`web/previews/f1-chat.png`](../previews/f1-chat.png)。

### 网关日志（同一轮）

```text
POST /api/v1/auth/register  201
POST /api/v1/auth/login     200
POST /api/v1/auth/refresh   200
GET  /api/v1/me             200
POST /api/v1/auth/logout    204
```

### 实现要点

- access token **只在内存**（`shared/api/session.ts`）；refresh 在 HttpOnly `ai_refresh` Cookie（B-08），JS 不可读。
- 刷新单飞：`refreshOnce()` 模块级 Promise；多标签用 `navigator.locks`（不可用时退化为单标签单飞）。
- 401 + `TOKEN_EXPIRED`：自动刷新并重放一次；`INVALID_REFRESH_TOKEN` 直接清态回登录。
- 错误统一成 `ApiError`，UI 展示 `code · message`，不吞后端文案。
- 登录、刷新、登出全部是真实请求；F1 不接会话与流式。
